# **Project: Incident Response Journal**

## **Objective**

This journal serves as a detailed log of various simulated security incidents. The purpose was to gain hands-on experience with common cybersecurity tools and to practice documenting the incident handling process, from initial detection to analysis and reflection.

## **Tools & Incidents Analyzed**

Throughout this journal, I used a variety of industry-standard tools to investigate different security scenarios:

* **VirusTotal:** Analyzed suspicious file attachments to identify malware by correlating file hashes with engine verdicts.  
* **Wireshark:** Performed packet analysis on .pcap files to inspect network protocols and filter for specific traffic patterns.  
* **tcpdump:** Captured live network traffic from specific interfaces and saved the output for later analysis.  
* **Suricata:** Utilized this Intrusion Detection System (IDS) to explore signature-based detection by running it with a custom rule and examining the output logs.  
* **Wazuh:** Queried this Security Information and Event Management (SIEM) tool to search for specific security events, such as failed SSH login attempts for a root account.

## **Skills Demonstrated**

* **Incident Handling:** Following a structured process for detection, analysis, and documentation.  
* **Hands-On Tool Usage:** Proficiency with Wireshark, Suricata, Wazuh, VirusTotal, and tcpdump.  
* **Technical Documentation:** Clearly and accurately documenting the "5 W's" of an incident (Who, What, When, Where, Why).  
* **Problem-Solving:** Reflecting on challenges, such as difficulties with VM configurations during a Wazuh setup, and finding solutions.
